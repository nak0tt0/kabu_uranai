# かぶうらない（Stock Mental Keeper）

保有銘柄の「購入動機や前提条件」を記録・可視化し、株価の乱高下による感情的な狼狽売りを防ぐ、投資心理管理サポートアプリです。

買った理由と「どうなったら売るか」を先に言語化しておくことで、相場の雰囲気に流されず、自分のシナリオに基づいて保有・売却を判断できる状態を目指します。

> 本アプリは投資判断の記録と振り返りを支援するもので、特定銘柄の売買を推奨する投資助言サービスではありません。

## コンセプト

- 購入動機・売却基準・買い増し条件を銘柄ごとに記録する
- 現在株価と損益を見える化し、当初のシナリオと照らし合わせる
- AIによる動機レビューや「握力復元」メッセージで、感情的な売買を抑える
- 木の育成（ゲーミフィケーション）で、保有と記録の継続を楽しくする

## 主な機能と実装状況

### ユーザー管理・認証

- ユーザー登録、ログイン／ログアウト、ゲストログイン（実装済み）
- マイページ：マイポートフォリオの一覧表示（整備中）
- 退会、パスワードリセット（予定）

### 銘柄・投資動機管理（コア機能）

- 銘柄登録：銘柄コード（例：7203、AAPL）、保有株数、取得単価（実装済み）
- 動機＆シナリオ入力：購入動機、売却基準・シナリオ、下落時の買い増し条件（整備中）
- グループ、タグ、振り返り記録（実装済み）

### 株価自動取得・損益可視化

- Yahoo Finance（yfinance）経由で現在株価・前日比を取得（実装途中：取得サービスはあるが画面未接続）
- 評価損益・騰落率の自動計算と表示（予定）

### AI投資心理サポート（構想）

- FOMOチェッカー：登録時に購入動機をAIがレビューし、感情的な飛びつき買いになっていないかをフィードバック
- 握力復元ボタン：急落時に、登録時の購入動機とAIの応援メッセージで初心を思い出す
- 購入条件チェッカー：「なぜ今買わないのか」「いくらになったら買うか」を記録し、条件達成度を整理

### 追加・拡張機能案（構想）

- 投資メンタルおみくじ／今日の心理診断（その日の相場環境や保有銘柄の動きに応じた投資運・アドバイス）
- パニックモード：売却前の15分冷却タイマーと、当初の売却条件との照合チェックリスト
- My投資憲章ダッシュボード：個人の投資ルールを常時上部に固定表示

### 木の育成（ゲーミフィケーション）

- 保有日数やマイルール遵守行動で経験値（EXP）を獲得し、木がレベルアップ（骨格実装済み・EXP獲得ループは整備中）
- 「実」の収穫とポイント蓄積（骨格実装済み）
- 外部ポイント交換連携（収益化フェーズで検討）

## 開発環境

- Windows 11 + WSL2（Ubuntu）+ VS Code（Remote WSL）
- ノートPC／デスクトップPCの2台で開発し、GitHub経由で同期する

### セットアップと起動

```bash
cd ~/kabu_uranai
git pull
bundle install
bin/rails db:prepare   # 初回のみ（seedでテスト用管理者も作成されます）
bin/rails s            # http://localhost:3000
```

PostgreSQLが起動していない場合は、先に起動してください。

```bash
sudo service postgresql start
```

## 開発の進め方

- ページ構成・要件は開発者が設計し、コードはAI支援で起案する。起案と検収は専用の開発ボードで行う
